# Vibe Track — tanıtım sitesi

https://onurfeyyaz.github.io/vibetrack-app/ (EN) · `/tr/` (TR)

Statik HTML, izleyici ve çerez yok, üçüncü taraf script yok.

- `src/` — şablon, stil, mood listesi (uygulamadan)
- `tools/prep_assets.py` — ekran görüntüleri (webp), ikonlar, OG kartları
- `tools/build.py` — `index.html` ve `tr/index.html` üretir
- `docs/kampanya-linki.md` — App Store kaynak takibi (`pt`) ve görsel yenileme

Metindeki her iddia uygulama koduna ya da canlı App Store açıklamasına dayanır.
